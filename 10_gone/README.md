# Effective Population Size Ne: GONE Official Workflow

The official Ne method in this directory is GONE (recent effective population size estimation based on linkage disequilibrium). 
## Command to Run

```bash
./03_run_selected_populations.sh
```

The default order is `Chillingham`, `swedish_modern`, `Swiss_modern`. You can also run only a specific population:

```bash
./03_run_selected_populations.sh Swiss_modern
```

The script calls `02_run_gone_population.sh` for each population, then generates a complete curve table, linear-scale plots, logarithmic-scale plots, a summary of changes, and an explanatory report. If valid `.ped/.map` files already exist, PLINK re-encoding is skipped; if completed markers and non-empty `Output_Ne_*` files are present, completed populations are skipped to ensure that resuming a interrupted run does not incur redundant processing time.

## Official Parameters

| Parameter | Value |
|---|---:|
| `PHASE` | 2 |
| `NGEN` | 2000 |
| `NBIN` | 400 |
| `MAF` | 0.0 |
| `REPS` | 40 |
| `threads` | 24 |

The default input is `results/05_variant_filtering/05_hwe1e-5`, and the population keep files are generated by `01_make_population_keep_files.py`. The GONE software version and archive checksum are recorded in `02_Parameters_Diagnostics/`.

## Interpretation of Boundaries

GONE’s curves reflect Ne under recent LD signals and are not equivalent to PSMC’s ancient population history curves. With only 6 individuals each in the Chillingham and Swedish modern populations, the results should be treated as exploratory evidence; LD, population structure, phase uncertainty, marker selection, and small sample sizes can all influence estimates of the most recent generation. The variation summary consists of descriptive statistics and should not be taken alone as proof of population expansion.
